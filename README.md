### [FlowForge](https://github.com/Surabin123/FlowForge)

**Local-first productivity with human-approved AI automation.** FlowForge turns a request into a validated workflow proposal, binds approval to the exact plan, executes registered tools, and keeps run and step history in SQLite. It addresses a key reliability gap in AI assistants: a proposed action is not evidence that an action ran successfully.

`Python` `FastAPI` `React` `TypeScript` `SQLite` `Workflow engine`

## How I approach engineering

- Define clear boundaries between UI, APIs, persistence, and integrations.
- Validate inputs at system boundaries and make important state changes observable.
- Treat AI output as untrusted input; require review and explicit approval before actions run.
- Document setup, operational constraints, and failure behavior alongside the code.
